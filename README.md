# Claude Skills for Education

**Open Claude skills for teachers, lecturers, trainers and L&D professionals: prompts, lessons, rubrics, test questions, feedback, inclusive materials and training programs.**

🌐 **[Website](https://thomasailuminated.github.io/claude-skills-for-education/)** · 🇧🇪 [Nederlands](#nederlands) · 🇬🇧 [English](#english)

Each skill is built on solid educational principles (constructive alignment, explicit instruction, feedback research, Universal Design for Learning), keeps the teacher in charge of judgment and grading, and works in Dutch, French and English.

| Skill | What it does | Download |
|---|---|---|
| [Edu Prompt Coach](https://github.com/ThomasAiluminated/edu-prompt-coach) | Ready-to-paste prompts for teachers, with the pedagogy behind them | [.skill](downloads/edu-prompt-coach.skill) |
| [Lesson Designer](https://github.com/ThomasAiluminated/lesson-designer) | Lessons designed from learning objective to exit check | [.skill](downloads/lesson-designer.skill) |
| [Rubric Builder](https://github.com/ThomasAiluminated/rubric-builder) | Fair assessment rubrics with observable levels and a student version | [.skill](downloads/rubric-builder.skill) |
| [Assessment Item Writer](https://github.com/ThomasAiluminated/assessment-item-writer) | Test and exam questions with plausible distractors, answer key and feedback | [.skill](downloads/assessment-item-writer.skill) |
| [Feedback Writer](https://github.com/ThomasAiluminated/feedback-writer) | Specific, actionable feedback on student work; the grade stays with you | [.skill](downloads/feedback-writer.skill) |
| [Inclusive Lesson Adapter](https://github.com/ThomasAiluminated/inclusive-lesson-adapter) | Accessible lesson materials using UDL, without lowering the objective | [.skill](downloads/inclusive-lesson-adapter.skill) |
| [Learning Program Designer](https://github.com/ThomasAiluminated/learning-program-designer) | Training programs from performance need to Kirkpatrick evaluation | [.skill](downloads/learning-program-designer.skill) |
| [Prompt Architect](https://github.com/ThomasAiluminated/prompt-architect) | Rough requests turned into strong, reusable prompts for Claude | [.skill](downloads/prompt-architect.skill) |

Every skill repo has a Dutch and an English README and an `examples/` folder with a full input and output.

## Nederlands

Een open reeks Claude-skills voor leerkrachten, docenten, trainers en L&D-professionals. Elke skill vertrekt van goede didactiek, laat het oordeel en het cijfer bij de leerkracht, en werkt in het Nederlands, Frans en Engels.

**Installeren in Claude (web, desktop of mobiel):**
1. Download het `.skill`-bestand van de skill die je wilt (zie de tabel hierboven)
2. Upload het bij de Skills in je Claude-instellingen, of open het bestand in een gesprek met Claude en klik op *Save skill*
3. Stel daarna gewoon je vraag, bv. *"maak een rubric voor stageverslagen"*. De skill start vanzelf.

**In Claude Code:** pak het `.skill`-bestand uit (het is een zip) en kopieer de map naar `~/.claude/skills/`.

## English

An open collection of Claude skills for teachers, lecturers, trainers and L&D professionals. Each skill is grounded in sound pedagogy, keeps judgment and grading with the teacher, and works in English, Dutch and French.

**Install in Claude (web, desktop or mobile):**
1. Download the `.skill` file for the skill you want (see the table above)
2. Upload it under Skills in your Claude settings, or open the file in a Claude conversation and click *Save skill*
3. Then just ask, e.g. *"make a rubric for internship reports"*. The skill starts automatically.

**In Claude Code:** unzip the `.skill` file and copy the folder to `~/.claude/skills/`.
